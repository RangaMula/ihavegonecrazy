# Master language list — every language a ভাষার দরজা book can be delivered for

Generated from `languages/master_languages.csv` by `languages/build_master.py`. Edit the CSV, not this file.

## Tiers (honest capability rating)

| Tier | Meaning | Count |
|---|---|---|
| **A** | I can write the whole book (sounds, script, grammar, 2,000-word journey, culture, dawah chapter) to a high standard. The standard human gates (native proofread, Bangla editor, audio) still apply. | 57 |
| **B** | I can write the whole book well, but there is less reference material, so expect more native-reviewer corrections. Budget a longer review. | 43 |
| **C** | Possible only with a native co-author. My output would be a structured first draft, not a finished book. | 43 |
| **Total** | | **143** |

**Not offered:** languages with no settled written standard or very little written material (most of the world's ~7,000 languages, e.g. small oral languages of Papua New Guinea, the Amazon and Central Africa); sign languages (they need video, not print); extinct or liturgical-only languages, apart from Latin and Sanskrit.

## Source flags

- **R**: already in the ভাষার দরজা roadmap (`SERIES-ROADMAP.md`)
- **K**: a KDP *Introduction to Arabic* edition exists for it on Drive
- **S**: in the KDP `SCHEDULE.md` Phase 2 queue
- **M**: in `KDP-Language-Opportunity-Matrix.csv`
- **✓**: book built (French)
