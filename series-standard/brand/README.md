# মাকতাবাতু কুনুজুল আখিরাহ — brand logos

Official publisher logos for every book of the ভাষার দরজা series.

| File | Use |
|---|---|
| `logo-bangla.png` | Title page, foreword signature block, Bangla-facing pages |
| `logo-english.png` | Copyright page, English-facing material, covers for international listings |
| `logo-arabic.png` | Language passport, Arabic-facing material, Islamic sections |
| `source-logo-*.webp` | Original artwork as supplied (white background) |

The PNG files are the originals with the outer white background made transparent and cropped to the emblem,
so they sit cleanly on the cream page colour.
