# Series Roadmap — ভাষার দরজা (book order)

One book per language, built in this order. Every book follows `BOOK-STRUCTURE.md` and carries the
same Bangla-only **লেখকের কথা** (`foreword/`).

## How the order was decided

Each book's position weighs four things:

1. **Reader demand among Bangla speakers:** work migration, higher study, religion, business and travel.
2. **Template risk first:** the first four books cover the four hardest script types (abjad, featural,
   kana + kanji, logographic + tones). Once those work, every later book is a variation the template
   already handles.
3. **Reuse:** books that share a script or research come right after each other (Arabic → Urdu → Persian;
   Malay → Indonesian; Hindi → Urdu).
4. **Effort ramp:** demanding books are spaced out with fast Latin-script books between them, to keep a
   steady release pace.

> The demand ranking is an editorial estimate. Before locking waves 2–4, check it against KDP and Rokomari
> search data and recent BMET migration figures.

## Pace (suggested)

| Phase | Books | Rough pace |
|---|---|---|
| Wave 1 | 1–4 | One book every 6–8 weeks (new script types; the template is built during Arabic) |
| Wave 2 | 5–10 | One every 3–4 weeks (Latin scripts, template stable) |
| Wave 3 | 11–14 | One every 4 weeks (script reuse from books 1 and 11) |
| Wave 4 | 15–18 | One every 3–4 weeks |

Every book still passes the human gates in `BOOK-STRUCTURE.md` §7 (native speaker, Bangla editor,
audio check) before upload. That review time, not production, will usually set the real pace.
