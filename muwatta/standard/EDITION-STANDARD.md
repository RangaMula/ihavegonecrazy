# Edition standard: bilingual Muwaṭṭaʾ (Arabic + one language per book)

Every language edition follows this file. The reasons for each rule are in `research/02-translation-mapping.md` §4.

## 1. What a reader sees for every entry

```
┌───────────────────────────────────────────────────────────────────────────────┐
│ Book 1 · The Times of Prayer · 3                    marfūʿ · grade: Ṣaḥīḥ      │  header (target language)
│                                                                               │
│      وَحَدَّثَنِي يَحْيَى، عَنْ مَالِكٍ، عَنْ زَيْدِ بْنِ أَسْلَمَ ... ‏                  │  1 Arabic, complete, vowelled (RTL)
│  ওয়াহ়াদ্দাথ়ানীː ইয়াহ়য়াː, ʿআন মাːলিক ...                                         │  2 pronunciation (generated)
│  সনদ: ইয়াহ্ইয়া ← মালিক ← যায়দ ইবনু আসলাম ← আতা ইবনু ইয়াসার                       │  3a chain of names
│  এক ব্যক্তি রাসূলুল্লাহ ﷺ-এর কাছে এসে ফজরের নামাজের সময় সম্পর্কে জিজ্ঞেস করল ...       │  3b meaning
│ ─ ইমাম মালিকের মন্তব্য ─────────────────────────────────────────────────────────  │  only if the entry has one
│      قَالَ مَالِكٌ ...                                                          │  4 same three layers
│  ক়াːলা মাːলিকুন ...                                                             │
│  মালিক বলেন: ...                                                               │
│  ¹ ফারসাখ: প্রায় ৫.৫ কিলোমিটার।                                                  │  5 notes
└───────────────────────────────────────────────────────────────────────────────┘
```

1. **Arabic.** The full text of the entry from `data/arabic/muwatta.json`, chain included, never shortened. Print the ﷺ
   formula as it stands in the Arabic, not as a ligature.
2. **Pronunciation.** Generated by `engine/` from the Arabic, using the language's scheme in `data/languages.csv`. It is
   never typed by hand: to fix a pronunciation, fix the engine or the Arabic. Languages that read Arabic script (Urdu,
   Persian, Pashto…) skip this line, because the vowelled Arabic already is their guide.
3. **Meaning.**
   - **3a, the chain:** the names of the narrators in order, joined with ←. Name forms come from the language's glossary.
   - **3b, the text:** a full, faithful translation of the rest of the narration from the Arabic, not from any other
     translation.
4. **Mālik's commentary** (segments with `kind: "malik"`) gets its own labelled block, with the same three layers.
5. **Notes**, numbered: units, people, places, a word the Arabic leaves implicit, and the meaning of يَعْنِي glosses where
   needed.

## 2. Translation rules (all languages)

1. **Translate from the Arabic.** Existing translations may be consulted for understanding, but never copied. They are
   copyrighted, and some contain errors (see the mapping study §3).
2. **Faithful, plain, modern.** Keep the order of events, the speakers and the punchlines. Do not summarise. Do not explain
   inside the text.
3. **[Square brackets]** only for a word the Arabic leaves implicit and the language needs:
   «مَا بَيْنَ هَذَيْنِ وَقْتٌ» → "Between these two is [the] time."
4. **No added honorifics in the translated text unless the language profile says so.**
   - The ﷺ formula is in the Arabic, so render it with the profile's form: «ﷺ», or the profile's word.
   - Companion eulogies are **not** in the Arabic. Add them only if the profile requires it (Bengali: (রা.) after a
     Companion, (রহ.) after a later scholar, the modern short forms). If added, use them the same way everywhere.
5. **Fixed formulas** (Mālik's technical expressions, transmission verbs, *qāla*, *yaʿnī*) use the renderings in
   `standard/glossary.json`, every time.
6. **Qurʾān quotations.** Follow the owner's protocol (`agents/islamic-source-verifier.md`):
   - Fetch the verse from quran.com and cross-check it against Tanzil. Never quote it from memory.
   - Inside a narration, the clause is the edition's own rendering and is labelled «ভাবার্থ / 意訳 / paraphrase».
   - The note gives the **whole verse**: the fetched Uthmani Arabic plus a **named QuranEnc translation**, unaltered and
     cited with its version (Bengali: Abu Bakr Muhammad Zakaria; Japanese: Saeed Sato).
   - Run `tools/verify_quran.py`.
7. **Units and money** (farsakh, ṣāʿ, mudd, wasq, dīnār, dirham) stay as they are in the text, with a note giving the
   modern equivalent the first time in each book.
8. **Proper names** use the language's established Muslim spelling (Bengali: আবু হুরায়রা, ইবনু শিহাব, উমার ইবনুল খাত্তাব;
   Japanese: アブー・フライラ, イブン・シハーブ). The pronunciation line still shows the exact Arabic reading.
9. **Arabic is never edited.** The printed Arabic is the source text verbatim (`tools/verify_hadith.py` checks it). A
   doubtful reading is explained in a note, citing only what the sources themselves show.
10. **Grade with grader, every entry.** Weak (da'if) entries carry the label "weak (da'if) per <grader>" and are never
    used as evidence; fabricated ones carry the label "fabricated (mawdu') per <grader>".
11. **Notes are editorial commentary.** They are labelled as such and are never presented as hadith. Claims about
    scholars' views need a source; without one, they are removed.
12. **Every edition is a REVIEW DRAFT** until a scholar who knows both Arabic and the target language has checked it. Print
   «REVIEW DRAFT / পর্যালোচনার খসড়া» on the title page and in the running footer.

## 3. Data format of a translation

`translations/<code>/book-NN.json`, one file per book of the Muwaṭṭaʾ:

```json
{
  "lang": "bn",
  "book": 1,
  "title": "নামাজের সময়",
  "status": "REVIEW DRAFT",
  "translator": "…",
  "reviewed_by": null,
  "entries": [
    {
      "n": 3,
      "nb": 3,
      "chain": ["ইয়াহ্ইয়া", "মালিক", "যায়দ ইবনু আসলাম", "আতা ইবনু ইয়াসার"],
      "text": "এক ব্যক্তি রাসূলুল্লাহ ﷺ-এর কাছে এসে…",
      "malik": null,
      "notes": ["…"]
    }
  ]
}
```

- `n` and `nb` must match the Arabic entry; the build fails if an entry is missing or extra.
- `chain`: narrators from Yaḥyā (or the first named narrator) down to the source. It is empty for entries that are
  wholly Mālik's words.
- `text`: translation of the `riwaya` segment, without the chain words («Yaḥyā related to me from Mālik from…»), which the
  chain line already shows.
- `malik`: translation of the `malik` segment(s), or `null`.
- No pronunciation is stored: it is generated at build time.

## 4. Language profile

`standard/profiles/<code>.json` gives the per-language choices the build and the translators need:

```json
{
  "code": "bn", "name": "বাংলা", "dir": "ltr", "pron_scheme": "bn",
  "labels": {"book": "অধ্যায়", "chain": "সনদ", "malik": "ইমাম মালিকের মন্তব্য", "grade": "মান", "notes": "টীকা",
             "types": {"marfu": "মারফূ‘", "mawquf": "মাওকূফ", "maqtu": "মাকতূ‘", "malik": "ইমাম মালিকের বক্তব্য"}},
  "eulogy_prophet": "ﷺ", "eulogy_companion": "(রা.)", "eulogy_scholar": "(রহ.)",
  "fonts": {"text": "Noto Serif Bengali", "pron": "Noto Sans Bengali"},
  "draft_notice": "পর্যালোচনার খসড়া — প্রকাশের আগে একজন আলেম দ্বারা যাচাই আবশ্যক"
}
```

## 5. Quality gates before any edition is published

0. **Authentication gate** (owner's protocol): `tools/verify_quran.py`, `tools/verify_hadith.py <book>` and
   `tools/build_sources_report.py <book>` produce:
   - a `.sources.md` report next to every edition;
   - the project file `VERIFIED-ISLAMIC-REFERENCES.md`;
   - bank additions.

   No FAILED or UNVERIFIED items may remain.

1. **Build gate.** `python3 tools/build_book.py <code>` passes: every entry is present, there are no tofu (missing-glyph)
   boxes, and pronunciation warnings are 0 (or listed).
2. **Self-check.** A second, independent pass compares every meaning against the Arabic: omissions, additions, names,
   numbers, negations, and who-said-what.
3. **Scholar review.** A ʿālim fluent in the language signs off book by book (`reviewed_by`).
4. **Native proofread** for language quality.
5. Only then is the REVIEW DRAFT notice removed.
