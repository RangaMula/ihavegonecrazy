# al-Muwaṭṭaʾ of Imām Mālik: bilingual editions from the Arabic

Every book of the Muwaṭṭaʾ (Yaḥyā al-Laythī recension), presented entry by entry as:

1. **the complete Arabic**, chain included, fully vowelled;
2. **its pronunciation in the reader's own script**, generated by rule from the vowelled Arabic;
3. **the meaning**, translated directly from the Arabic, with the chain as a line of names;
4. **Imām Mālik's own commentary**, separated and labelled. It makes up about 26% of the book, and every existing
   translation runs it into the ḥadīth text.

Target languages: the series master list (143 languages) plus Bengali, recorded in `data/languages.csv`.

**Every edition is a REVIEW DRAFT.** These are AI translations of ḥadīth. A scholar who knows both Arabic and the target
language must check each book before anything is published (standard §5).

## Build

```bash
python3 tools/build_dataset.py          # Arabic dataset (downloads the sources into .cache/)
python3 tools/check_pron.py bn          # run a pronunciation scheme over every entry
cd tools && npm install && cd ..        # fonts (SIL OFL), once
python3 tools/build_book.py bn --books 1   # editions/bn/muwatta-bn-book01.html + .pdf
python3 tools/build_registry.py         # data/languages.csv
```

## Publishing (Maktabatu Kunujul Akhirah)

```bash
python3 tools/build_release.py bn --volume 1     # -> editions/bn/release/vol01/
```

| File | For |
|---|---|
| `interior.pdf` | paperback interior: 6 × 9 in, no bleed, fonts embedded, even page count (KDP, IngramSpark, Lulu, local printers) |
| `cover.pdf` | full-wrap cover: exact size from the page count, 0.125 in bleed, 2 × 1.2 in barcode area |
| `ebook.epub` + `ebook-cover.jpg` | EPUB 3, 0 errors in EPUBCheck; Kindle (KDP), Google Play Books, Apple Books, Kobo, Draft2Digital |
| `metadata.json`, `PUBLISHING-GUIDE.md` | titles, contributors, description, keywords, BISAC, AI disclosure, store-by-store steps |

- **Publisher:** Maktabatu Kunujul Akhirah (an imprint of the Kunujul Akhirah Charitable Trust), Dhaka.
- **Copyright:** © 2026 Maktabatu Kunujul Akhirah, all rights reserved.
- **Editor:** Hafez Abdullah Muhammad Minhaz Reza.
- **Author:** Imām Mālik ibn Anas.

All of this is in `standard/publishing.json`.

**To make a volume upload-ready:**

1. Have a scholar review it, then set `reviewed_by` in each `translations/<code>/book-NN.json`. This removes every
   REVIEW DRAFT notice and prints the reviewer's name on the copyright page.
2. Put the ISBNs in `standard/publishing.json` → `editions.<code>.isbn` (one per format). The ISBN then appears on the
   copyright page, and a scannable EAN-13 barcode is drawn on the back cover.
3. Rebuild, order a printed proof, then upload following `PUBLISHING-GUIDE.md`.


## Scaling up to the whole book in every language

Size of the job: 1,860 entries (about 120,000 Arabic words) × 143 more languages, which is about 265,000 entry
translations. Each new language needs:

1. a profile (`standard/profiles/<code>.json`);
2. a pronunciation renderer, where its script is not ready yet;
3. 61 translation files;
4. an independent review pass;
5. human scholarly review.

Rough model cost for steps 3–4, from the pilot's measured size (about 1.4M input and 0.6M output tokens per language for
the whole book; OpenRouter batch prices, Nov 2026):

| Route | 142 languages, translation + review pass |
|---|---|
| Claude Sonnet 5.5 (batch) | about $1,000 |
| Claude Opus 5.5 (batch) | about $2,000 |

The translation prompt is simply: `standard/EDITION-STANDARD.md` + `glossary.json` + the profile + one book's Arabic,
returning the JSON format of §3. `tools/build_book.py` then rejects any book with missing or extra entries.

The real bottleneck is step 5. Tier C languages in the master list (Dhivehi, Santali, Tibetan…) need a native
co-author, not just a reviewer.
